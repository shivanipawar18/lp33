============================================================ SECTION 1: MACHINE LEARNING (ML)
A. MACHINE LEARNING BASICS

What is Machine Learning? Answer: Machine Learning is a branch of Artificial Intelligence that allows computers to learn patterns from data and make predictions or decisions without being explicitly programmed for every task.

What is Artificial Intelligence? Answer: Artificial Intelligence (AI) is the ability of machines to perform tasks that normally require human intelligence, such as learning, reasoning, and problem-solving.

What is the difference between AI and ML? Answer: AI is the broader field of making machines intelligent. Machine Learning is a part of AI in which machines learn from data.

What are the main types of Machine Learning? Answer:

Supervised Learning: Learns from labelled data.
Unsupervised Learning: Finds patterns in unlabelled data.
Reinforcement Learning: Learns by receiving rewards or penalties for actions.
What is supervised learning? Answer: Supervised learning uses input data along with known output labels to train a model.

What is unsupervised learning? Answer: Unsupervised learning uses data without output labels and discovers hidden patterns or groups.

What is a dataset? Answer: A dataset is a collection of data arranged in rows and columns.

What are features? Answer: Features are the input variables used by a machine learning model to make predictions.

What is a target variable? Answer: The target is the output variable that the model tries to predict.

What is training data? Answer: Training data is the part of the dataset used to teach the model.

What is testing data? Answer: Testing data is unseen data used to evaluate how well the trained model performs.

Why do we split data into training and testing sets? Answer: We split data to train the model on one portion and check its performance on unseen data. This helps estimate how well it may work on new data.

What is overfitting? Answer: Overfitting occurs when a model learns the training data too closely, including noise, and performs poorly on new data.

What is underfitting? Answer: Underfitting occurs when a model is too simple to learn the important patterns in the data.

What is data preprocessing? Answer: Data preprocessing means cleaning and preparing raw data before giving it to a machine learning model.

Why do we handle missing values? Answer: Missing values can affect calculations and model training. We may remove them or replace them using a suitable method.

What is an outlier? Answer: An outlier is a value that is unusually high or low compared with most other values in the dataset.

What is the IQR method? Answer: IQR means Interquartile Range. It is calculated as Q3 minus Q1. A common rule identifies values below Q1 - 1.5 times IQR or above Q3 + 1.5 times IQR as outliers.

What is feature scaling? Answer: Feature scaling brings numerical features to comparable ranges so that large-valued features do not dominate distance-based algorithms.

What is StandardScaler? Answer: StandardScaler transforms features so that they have approximately mean 0 and standard deviation 1, based on the training data.

What is a pipeline in machine learning? Answer: A pipeline combines preprocessing steps and a machine learning model into one sequence.

What is random_state? Answer: random_state fixes the random process so that results such as data splitting can be reproduced.

What is stratify in train_test_split? Answer: stratify maintains approximately the same class proportions in training and testing sets.

What is classification? Answer: Classification predicts a category or class, such as spam or not spam.

What is regression? Answer: Regression predicts a continuous numerical value, such as a house price or taxi fare.

B. KNN ALGORITHM

What is KNN? Answer: K-Nearest Neighbors is a supervised learning algorithm used for classification and regression. It makes a prediction using the nearest data points.

How does KNN work? Answer:

Choose the value of K.
Calculate the distance between the new point and training points.
Select the K nearest points.
For classification, choose the majority class among those neighbors.
What does K represent in KNN? Answer: K represents the number of nearest neighbors considered for prediction.

What is Euclidean distance? Answer: Euclidean distance is the straight-line distance between two points. For two dimensions, it is the square root of the sum of squared coordinate differences.

Why is feature scaling important for KNN? Answer: KNN uses distance calculations. A feature with a large numerical range could dominate the distance if features are not scaled.

What happens if K is too small? Answer: The model may become sensitive to noise and overfit.

What happens if K is too large? Answer: The model may become too smooth and underfit.

Is KNN supervised or unsupervised? Answer: KNN is a supervised learning algorithm.

C. SUPPORT VECTOR MACHINE (SVM)

What is SVM? Answer: Support Vector Machine is a supervised learning algorithm that finds a decision boundary to separate classes.

What is a hyperplane? Answer: A hyperplane is the decision boundary used by SVM to separate different classes.

What are support vectors? Answer: Support vectors are the training data points closest to the decision boundary. They help determine the boundary.

What is the margin in SVM? Answer: The margin is the distance between the decision boundary and the closest data points from each class. SVM tries to maximize this margin.

What is LinearSVC? Answer: LinearSVC is an implementation of a linear Support Vector Classifier in scikit-learn.

What does parameter C do in LinearSVC? Answer: C controls the penalty for classification errors. A larger C penalizes errors more strongly and may produce a narrower margin.

G. MODEL EVALUATION

What is accuracy? Answer: Accuracy is the proportion of all predictions that are correct.

What is precision? Answer: Precision tells us, out of all positive predictions, how many are actually positive.

What is recall? Answer: Recall tells us, out of all actual positive cases, how many the model correctly identifies.

What is F1 score? Answer: F1 score is the harmonic mean of precision and recall. It is useful when we want to balance both.

What is a confusion matrix? Answer: A confusion matrix compares actual classes with predicted classes.

What are TP, TN, FP, and FN? Answer:

TP (True Positive): Positive case correctly predicted as positive.
TN (True Negative): Negative case correctly predicted as negative.
FP (False Positive): Negative case incorrectly predicted as positive.
FN (False Negative): Positive case incorrectly predicted as negative.
What is specificity? Answer: Specificity measures the proportion of actual negative cases correctly identified. Formula: TN / (TN + FP).

What is balanced accuracy? Answer: Balanced accuracy is the average recall obtained for each class. It is useful when classes are imbalanced.

What is R-squared (R2)? Answer: R2 measures how well a regression model explains the variation in the target. A higher value is generally better.

What is MAE? Answer: Mean Absolute Error is the average absolute difference between actual and predicted values. Lower is better.

What is RMSE? Answer: Root Mean Squared Error is the square root of the average squared prediction error. It penalizes large errors more heavily. Lower is better.

What is the difference between classification and regression metrics? Answer: Classification commonly uses accuracy, precision, recall, and F1 score. Regression commonly uses MAE, RMSE, and R2.

============================================================ SECTION 2: BLOCKCHAIN TECHNOLOGY (BLT)
A. BLOCKCHAIN BASICS

What is Blockchain? Answer: Blockchain is a distributed digital ledger that stores records in blocks connected using cryptographic hashes.

Why is it called a blockchain? Answer: Because blocks of records are linked together in a chain using hashes.

What is a block? Answer: A block is a data structure that stores transactions or records along with information such as a timestamp and the previous block’s hash.

What is a hash? Answer: A hash is a fixed-length output generated from input data using a hash function.

What is cryptographic hashing? Answer: It is the process of converting data into a fixed-length hash using a mathematical algorithm.

Which hash algorithm is commonly used in Bitcoin? Answer: Bitcoin uses SHA-256 as part of its proof-of-work process.

What is a distributed ledger? Answer: A distributed ledger is a record of transactions shared and maintained across multiple computers or nodes.

What is decentralization? Answer: Decentralization means control and data are not held by only one central authority.

What is immutability? Answer: Immutability means that recorded data is designed to be very difficult to change without detection or network agreement.

Is blockchain completely unchangeable? Answer: No system is absolutely impossible to change. Blockchain makes unauthorized changes difficult through cryptography and consensus mechanisms.

What is a node? Answer: A node is a computer that participates in a blockchain network by storing, validating, or sharing blockchain data.

What is a peer-to-peer network? Answer: It is a network in which computers communicate and share information directly without depending entirely on a central server.

What is a consensus mechanism? Answer: It is a method that allows network participants to agree on the valid state of the blockchain.

What is a public blockchain? Answer: A public blockchain is open for anyone to participate in, subject to its protocol rules.

What is a private blockchain? Answer: A private blockchain restricts participation to authorized users or organizations.

What is a permissioned blockchain? Answer: It is a blockchain in which access or participation is controlled by permissions.

What is the difference between public and private blockchain? Answer: Public blockchains are generally open to everyone, while private blockchains restrict access to approved participants.

What is a genesis block? Answer: The genesis block is the first block in a blockchain.

What is a timestamp? Answer: A timestamp records the time associated with a block or transaction.

What is a nonce? Answer: A nonce is a number used in certain cryptographic processes. In proof of work, miners vary the nonce while searching for a valid block hash.

B. CRYPTOGRAPHY AND CONSENSUS

What is encryption? Answer: Encryption converts readable information into an unreadable form using a key. It protects confidentiality.

What is the difference between hashing and encryption? Answer: Hashing is designed to be one-way. Encryption is designed to be reversible by someone with the correct decryption key.

What is a public key? Answer: A public key is a cryptographic key that can be shared publicly and is used in operations such as verifying digital signatures.

What is a private key? Answer: A private key is secret information used to control an account or sign transactions. It must never be shared.

What is a digital signature? Answer: A digital signature is a cryptographic proof that helps verify the authenticity and integrity of a signed message or transaction.

What is Proof of Work (PoW)? Answer: Proof of Work is a consensus mechanism in which participants perform computational work to propose blocks.

What is Proof of Stake (PoS)? Answer: Proof of Stake is a consensus mechanism in which validators are selected and participate based partly on cryptocurrency they have staked.

What is mining? Answer: Mining is the process used in proof-of-work blockchains to validate and add blocks by performing computational work.

What is a validator? Answer: A validator is a participant responsible for proposing or checking blocks in a proof-of-stake blockchain.

What is a 51% attack? Answer: It is an attack scenario in which an entity controls a majority of a network’s relevant consensus power, potentially allowing it to reorganize recent transactions or disrupt the network.

What is Bitcoin? Answer: Bitcoin is a decentralized digital currency that operates on a peer-to-peer blockchain network.

Who introduced Bitcoin? Answer: Bitcoin was introduced by the pseudonymous person or group known as Satoshi Nakamoto.

What is Ethereum? Answer: Ethereum is a blockchain platform that supports smart contracts and decentralized applications.

What is Ether? Answer: Ether (ETH) is the native cryptocurrency of the Ethereum network.

What is the difference between Bitcoin and Ethereum? Answer: Bitcoin mainly focuses on peer-to-peer digital money. Ethereum also provides a programmable platform for smart contracts and decentralized applications.

What is a cryptocurrency? Answer: A cryptocurrency is a digital asset that uses cryptography and typically operates on a blockchain or similar distributed system.

What is a wallet? Answer: A cryptocurrency wallet manages keys used to access and authorize transactions associated with blockchain accounts.

Does a wallet store coins physically? Answer: No. The blockchain records balances and transactions. A wallet manages the keys used to access them.

What is MetaMask? Answer: MetaMask is a cryptocurrency wallet commonly used to interact with Ethereum and compatible blockchain networks.

What is a testnet? Answer: A testnet is a blockchain network used for testing applications and transactions without using real mainnet funds.

What is the mainnet? Answer: The mainnet is the live blockchain network where real transactions take place.

What is Solidity? Answer: Solidity is a programming language used to write smart contracts for the Ethereum Virtual Machine and compatible platforms.

What is Remix IDE? Answer: Remix is a browser-based development environment used to write, compile, deploy, and test Solidity smart contracts.

============================================================ SECTION 3: DESIGN AND ANALYSIS OF ALGORITHMS (DAA)
A. ALGORITHM BASICS

What is an algorithm? Answer: An algorithm is a finite sequence of clear steps used to solve a problem.

What are the characteristics of an algorithm? Answer:

Input: It may accept zero or more inputs.
Output: It produces at least one result.
Definiteness: Each step is clear.
Finiteness: It terminates after a finite number of steps.
Effectiveness: Each step can be performed.
What is time complexity? Answer: Time complexity describes how the running time of an algorithm grows as the input size increases.

What is space complexity? Answer: Space complexity describes how much memory an algorithm uses as the input size increases.

What is asymptotic analysis? Answer: Asymptotic analysis studies the growth of an algorithm’s resource usage for large input sizes.

What is Big O notation? Answer: Big O describes an asymptotic upper bound on the growth rate of an algorithm.

What is Omega notation? Answer: Omega describes an asymptotic lower bound on the growth rate.

What is Theta notation? Answer: Theta describes a tight asymptotic bound when upper and lower bounds have the same growth rate.

What is best-case complexity? Answer: It is the minimum work an algorithm performs for an input of a particular size.

What is average-case complexity? Answer: It is the expected work over inputs of a particular size, based on an assumed input distribution.

What is worst-case complexity? Answer: It is the maximum work an algorithm performs for inputs of a particular size.

What is recursion? Answer: Recursion is a programming technique in which a function calls itself to solve smaller versions of a problem.

What is a base case? Answer: A base case is the stopping condition that prevents recursive calls from continuing forever.

What is iteration? Answer: Iteration repeats a set of instructions using loops such as for or while.

What is the difference between recursion and iteration? Answer: Recursion uses function calls and a call stack. Iteration uses loops and usually requires less function-call overhead.

B. SEARCHING ALGORITHMS

What is searching? Answer: Searching is the process of finding a required element in a collection of data.

What is Linear Search? Answer: Linear Search checks elements one by one until the target is found or the collection ends.

What is the time complexity of Linear Search? Answer:

Best case: O(1)
Average case: O(n)
Worst case: O(n)
Does Linear Search require sorted data? Answer: No. It works on both sorted and unsorted data.

What is Binary Search? Answer: Binary Search repeatedly divides a sorted search range into two halves to find the target.

What is the main condition for Binary Search? Answer: The data must be sorted.

What is the time complexity of Binary Search? Answer:

Best case: O(1)
Average and worst case: O(log n)
Why is Binary Search faster than Linear Search for large sorted data? Answer: Binary Search removes half of the remaining search range at every step, while Linear Search checks elements one by one.

What are low, high, and mid in Binary Search? Answer:

low: Starting index of the current search range.
high: Ending index of the current search range.
mid: Middle index, commonly calculated as low + (high - low) / 2.
C. SORTING ALGORITHMS

What is sorting? Answer: Sorting is arranging data in a particular order, such as ascending or descending order.

What is Bubble Sort? Answer: Bubble Sort repeatedly compares adjacent elements and swaps them if they are in the wrong order.

What is the time complexity of Bubble Sort? Answer:

Average case: O(n^2)
Worst case: O(n^2)
Best case: O(n) when an optimized version detects that no swaps are needed.
What is Selection Sort? Answer: Selection Sort repeatedly finds the smallest element from the unsorted part and places it at the beginning of that part.

What is the time complexity of Selection Sort? Answer: Best, average, and worst cases are O(n^2).

What is Insertion Sort? Answer: Insertion Sort builds a sorted portion by taking one element at a time and inserting it into its correct position.

What is the time complexity of Insertion Sort? Answer:

Best case: O(n)
Average case: O(n^2)
Worst case: O(n^2)
Which sorting algorithm is suitable for nearly sorted data? Answer: Insertion Sort is often efficient for small or nearly sorted datasets.

What is Merge Sort? Answer: Merge Sort divides the array into smaller parts, sorts them recursively, and merges the sorted parts.

What is the time complexity of Merge Sort? Answer: O(n log n) in best, average, and worst cases.

What is the space complexity of Merge Sort? Answer: Standard array-based Merge Sort generally requires O(n) auxiliary space.

What is Quick Sort? Answer: Quick Sort selects a pivot, partitions elements around it, and recursively sorts the resulting parts.

What is a pivot? Answer: A pivot is the selected element used to divide the array during Quick Sort.

What is partitioning? Answer: Partitioning rearranges elements so that values on one side of the pivot are smaller and values on the other side are larger, according to the chosen partition rule.

What is the time complexity of Quick Sort? Answer:

Best and average case: O(n log n)
Worst case: O(n^2)
What is Randomized Quick Sort? Answer: Randomized Quick Sort chooses the pivot randomly to reduce the chance of repeatedly getting highly unbalanced partitions.

What is the difference between Merge Sort and Quick Sort? Answer: Merge Sort has O(n log n) worst-case time and usually needs O(n) extra array space. Quick Sort has O(n log n) average time, O(n^2) worst-case time, and is often implemented in-place.

D. DIVIDE AND CONQUER

What is Divide and Conquer? Answer: It is a problem-solving technique that divides a problem into smaller subproblems, solves them, and combines their results.

What are the three steps of Divide and Conquer? Answer:

Divide: Break the problem into smaller subproblems.
Conquer: Solve the subproblems.
Combine: Combine their solutions.
Give examples of Divide and Conquer algorithms. Answer: Binary Search, Merge Sort, and Quick Sort.

Why is Merge Sort a Divide and Conquer algorithm? Answer: It divides the array into halves, recursively sorts each half, and merges the sorted halves.

E. GREEDY ALGORITHMS

What is a Greedy Algorithm? Answer: A Greedy Algorithm makes the best locally available choice at each step, hoping to obtain a good overall solution.

Does a greedy algorithm always give the optimal solution? Answer: No. It gives an optimal solution only when the problem has the required greedy-choice property and optimal substructure.

What is Fractional Knapsack? Answer: Fractional Knapsack is an optimization problem in which we can take a fraction of an item to maximize total profit within a weight limit.

Which approach is used for Fractional Knapsack? Answer: A greedy approach is used. Items are sorted by profit-to-weight ratio in descending order.

What is the time complexity of Fractional Knapsack? Answer: O(n log n), mainly because of sorting the items.

What is the difference between Fractional and 0/1 Knapsack? Answer: Fractional Knapsack allows taking part of an item. 0/1 Knapsack allows either taking the whole item or not taking it.

What is Huffman Coding? Answer: Huffman Coding is a greedy algorithm that creates variable-length prefix codes based on character frequencies.

What is a prefix code? Answer: A prefix code is a code in which no symbol’s code is the prefix of another symbol’s code.

Why is Huffman Coding used? Answer: It reduces the average number of bits needed to represent symbols and is used in lossless data compression.

Which data structure is used in Huffman Coding? Answer: A priority queue, commonly implemented using a min-heap, selects the two nodes with the lowest frequencies.

What is the time complexity of Huffman Coding? Answer: O(n log n) when a priority queue is used for n distinct symbols.

F. DYNAMIC PROGRAMMING

What is Dynamic Programming? Answer: Dynamic Programming solves problems by breaking them into overlapping subproblems and storing their results to avoid repeated calculations.

What are overlapping subproblems? Answer: They occur when the same smaller problems are solved repeatedly.

What is optimal substructure? Answer: A problem has optimal substructure when an optimal solution can be built from optimal solutions to its smaller subproblems.

What are the two approaches to Dynamic Programming? Answer:

Memoization: Top-down approach using recursion and storing results.
Tabulation: Bottom-up approach using a table.
What is the 0/1 Knapsack problem? Answer: It is an optimization problem where each item can either be selected completely or rejected, with the goal of maximizing profit within a weight capacity.

What is the recurrence relation for 0/1 Knapsack? Answer: If item i has weight wt[i] and profit val[i], then:

If wt[i] is greater than capacity w, exclude the item.
Otherwise, take the maximum of excluding it and including it: dp[i][w] = max(dp[i-1][w], val[i] + dp[i-1][w-wt[i]]).
What is the time complexity of 0/1 Knapsack using tabulation? Answer: O(nW), where n is the number of items and W is the capacity.

What is the space complexity of the standard 2D DP solution? Answer: O(nW).

What is the difference between Greedy and Dynamic Programming? Answer: Greedy makes a local choice at each step. Dynamic Programming compares solutions to subproblems and stores results to obtain an optimal solution when its conditions apply.

G. BACKTRACKING

What is Backtracking? Answer: Backtracking builds a solution step by step. If a choice cannot lead to a valid solution, it undoes that choice and tries another.

What is the N-Queens problem? Answer: The N-Queens problem asks us to place N queens on an N by N chessboard so that no two queens attack each other.

Why can two queens not be in the same row or column? Answer: A queen can attack horizontally, vertically, and diagonally. A valid arrangement must avoid all these conflicts.

How does the N-Queens algorithm work? Answer:

Place a queen in a safe position in the current row.
Move to the next row recursively.
If no safe position is available, remove the previous queen and try another position.
If all queens are placed, a solution is found.
What is the purpose of the isSafe() function? Answer: It checks whether a queen can be placed at a given position without attacking another queen.

What is backtracking in N-Queens? Answer: If a queen placement prevents a complete solution, the algorithm removes that queen and tries a different column.

What is the base case in N-Queens? Answer: When all N rows have been filled with queens, a valid solution has been found.

What is the difference between recursion and backtracking? Answer: Recursion is a technique in which a function calls itself. Backtracking is a problem-solving strategy that often uses recursion to explore choices and undo invalid ones.

H. FIBONACCI AND COMPLEXITY

What is the Fibonacci series? Answer: It is a sequence in which each number is the sum of the previous two numbers. A common starting sequence is 0, 1, 1, 2, 3, 5, 8.

What is the Fibonacci recurrence relation? Answer: F(n) = F(n-1) + F(n-2), with F(0) = 0 and F(1) = 1.

What is the time complexity of iterative Fibonacci? Answer: O(n), because the loop calculates each term once.

What is the time complexity of naive recursive Fibonacci? Answer: O(2^n) as a common upper-bound description, because it repeatedly recalculates the same values.

How can recursive Fibonacci be optimized? Answer: Use memoization or dynamic programming to store already calculated Fibonacci values.

What is a comparison count? Answer: It is the number of comparisons performed by an algorithm according to the specific comparisons counted in the program.
